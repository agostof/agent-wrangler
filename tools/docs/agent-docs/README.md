# Agent Docs

## Audience

AI agents and human operators auditing agent assumptions.

## Purpose

This directory contains only agent-relevant guidance for using the `/tools` indexing scripts:
- when to use them
- how to sequence them
- what not to assume from their outputs

It does not contain human runbooks. For operator procedure, see [operator-docs/README.md](/tools/docs/operator-docs/README.md).
